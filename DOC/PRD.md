# VANNIC DYNAVION Website — Product Requirements Document

## 1. Project Overview

Build a premium, production-ready corporate website for **VANNIC DYNAVION PRIVATE LIMITED**.

Primary domain:

`https://www.vannicdynavion.com`

Brand:

**VANNIC**

Core platform:

**VANNIC GRiDMiND**

Tagline:

**Intelligence Behind Every Kilowatt.**

The website must position VANNIC as an industrial technology company developing intelligent monitoring, edge-control and analytics systems for commercial and industrial electrical infrastructure.

The website must avoid looking like a generic SaaS template or dashboard-only startup.

---

## 2. Core Positioning

VANNIC is developing an intelligent electrical infrastructure platform that combines:

- Real-time electrical monitoring
- Electrical abnormal-condition detection
- Event logging
- Priority-based load management
- Approved non-critical load control
- Edge intelligence
- Cloud dashboards
- Predictive analytics

The product vision is to help facilities move from reactive electrical monitoring toward preventive, data-driven electrical operations.

## 4. Website Goals

The website must:

1. Explain what VANNIC does within 10 seconds.
2. Communicate the difference between monitoring and preventive action.
3. Present VANNIC as a hardware + edge intelligence + software company.
4. Explain GRiDMiND clearly.
5. Show relevant electrical infrastructure use cases.
6. Support pilot and demo enquiries.
7. Build technical credibility without unsupported claims.
8. Work well on desktop, tablet, mobile, and half-window browser layouts.

## 10. Content Rules

Do not fabricate:

- Customers
- Deployments
- Savings percentages
- Awards
- Patents
- Certifications
- Partnerships
- Revenue
- AI accuracy
- Product certifications
- Employee count
- Install base
- Testimonials

If data is simulated in UI mockups, clearly present it as visual demonstration data.

---

## 11. Success Criteria

The website is successful if:

- A new visitor understands VANNIC's purpose quickly.
- The site feels like an industrial technology company, not a generic SaaS startup.
- Hardware, edge intelligence and software are visibly connected.
- Key CTAs are easy to find.
- Mobile layout is genuinely designed rather than compressed desktop UI.
- The codebase is clean, maintainable and production-ready.
